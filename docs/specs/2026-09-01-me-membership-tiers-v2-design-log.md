## 背景

2026-08-31 产品负责人拍板了 ME 会员制度 v1.1（免费 / $39 / $199 / $499 / 定制），已经立项的四张票是 [#1273](https://github.com/bigbigraydeng-maker/magic-engine/issues/1273)（免费站生成器）、[#1274](https://github.com/bigbigraydeng-maker/magic-engine/issues/1274)（免费档生命周期）、[#1275](https://github.com/bigbigraydeng-maker/magic-engine/issues/1275)（$39 订阅）、[#1276](https://github.com/bigbigraydeng-maker/magic-engine/issues/1276)（扫街预建站），全部还是 SPEC DRAFT。

这四张票定义的免费/$39 档是"网站阶梯"（先给网站，再解锁域名/邮箱），完全没碰到 6 大支柱（SEO / 社媒 / 广告 / 口碑 / AI 可见度 / 竞品）。2026-09-01 起，产品负责人要重新设计**这条阶梯之上、6 支柱怎么分布到各档**的服务内容和定价——**框架不变（网站阶梯是地基），内容和定价要重新设计**。

$199 / $499 目前完全没有 spec，`docs/registry/pricing-playbook-enterprise-fde.md` 明确写着"报价材料禁止承诺这两档，除非订阅契约先落地"。

## 已定（截至 2026-09-01）

### 总体框架
- **不推翻 #1273-1276 的地基**，免费/$39 档的"网站+域名+邮箱"部分保留；这次重新设计的是**6 支柱在各档怎么分布 + 定价 + 具体额度**
- CRM / 邮件读取等工具走 **Connector 原则**：会积累数据、越用越准的判断层（学习型能力）—— ME 自己造（L1）；其他一切能买/能接的 —— 用 Connector 接，是"ME 帮你配好的工具"，不代表 ME 要重新发明它。跟已冻结的公司级战略决策 [#1131](https://github.com/bigbigraydeng-maker/magic-engine/issues/1131) 一致（ME 不做完整 CRM 公司，只做 CRM 之上的 Marketing-to-Sales 判断层）

### 免费档
- 定位：**数字基建，不是支柱能力**。6 支柱要等基建就绪后才能展开
- 功能：二级域名网站（一次性开发，边际成本近零）+ 每月一次网站流量报告 + 每日查收邮件内容
- **"每日查收邮件内容"是新能力，还没建过**——已记为待登记候选（不是 CTS 那种单客户定制邮箱托管，是面向所有自助客户的通用产品功能），登记判定推迟到设计定稿后再走 [me-platform-tier-gate](../../.claude/skills/me-platform-tier-gate/SKILL.md) 完整流程
- 名额策略未最终拍板（见"待定"）

### $39 档
- 核心原则：**"麻雀虽小，五脏俱全"**——哪怕功能窄，也必须是一个完整 IMPACT 闭环（发现问题 + 客户能自己动手 + 能看到结果变化），不能只给诊断不给"能自己修"的东西
- 支柱不强制每档都有，按**"AI 能不能独立判断 + 有没有对外发布/花钱风险"**排序进场，顺序由产品经理故意设计，用来引导客户往上升级：
  - **AI 可见度**：月度监控（1 个引擎，ChatGPT）+ 客户能自己动手的小任务（具体任务待定）
  - **竞品监控**：只读监控，无发布动作
  - **SEO**：轻量强度（弱于 $199），参考 Semrush 的打法（细节待定）
  - **口碑**：不止 GBP，还有行业专属口碑网络（餐饮、旅游各自的点评平台），前提是客户自己去授权绑定——这些行业专属 Connector 以后逐个接入时按 L2 Playbook 登记，非阻塞
  - **社媒（内容工厂：图片/视频）**：从 $39 起有，但数量/强度受限
  - **广告**：$39 不给，从 $199 才开始有

### $39 档成本测算（真实数字，不是拍脑袋）
- 目标毛利 ≥80%，但 **80% 不能只算 compute 成本**——Stripe 手续费（2.9% + $0.30/笔）在 $39 这么薄的档位上就已经占了 3.7%，还没算客服/获客/基础设施
- 真实成本基准（引用 Claude 跨会话 memory `reference-ai-api-unit-costs-2026-08`，2026-08 公开定价，不在本仓库内，下次续聊时 Claude 会自动带上）：诊断/监控类 AI 调用每次 ~$0.05-0.30 NZD；图片 ~$0.03-0.05 NZD/张；**视频是全场景唯一真正烧钱的项目**，最低配（480p·6 秒）也要 ~$0.6-1 NZD，720p·15 秒能到 $4+
- **基础额度包**（compute 成本约 $1-2/用户/月，毛利 95%+）：4 项监控（AI 可见度/竞品/SEO/口碑）各每月 1 次 + 图片 10-15 张/月 + **视频 0 条（含在月费内）**
- **"挖爽感"加码版**（compute 成本约 $2-4/用户/月，毛利仍 90-95%）：AI 可见度监控从月度提到周度 + 每月送 1 条最低配视频（480p·6 秒）+ 每月一份可分享的"增长战报"一页纸（复用诊断报告生成器，几乎零成本，顺带是免费传播钩子）
- 技术实现：**复用现有 MTC 账本**（`src/lib/mtc/`），不新造配额系统——把"一次性买 MTC"扩展成"$39 订阅每月自动发一批 MTC"，这本来就是 #1275 的范围；视频/图片复用现成的视频工厂后台，不重造

## 待定（下次接着问）

1. **$39 额度到底要不要含 1 条最低配视频**——"挖爽感加码版"已经给出成本对比（毛利 95%+ → 90-95%），产品负责人还没拍板选哪版
2. **免费档"100 个名额"是一次性测试期定语，还是长期就限量制**——产品负责人说"看转化率再定，转化好可以补贴长期跑"，但这跟 #1274"永久免费不设上限"+ #1276 扫街批量预建站的玩法有冲突，需要在有转化数据后回来对齐
3. **$199 / $499 在 SEO / 口碑 / 社媒 / 竞品支柱上的具体额度矩阵**——目前只有 AI 可见度支柱（$199=GEO 修复优化开始，$499=全平台监控+GEO优化+关键渠道 keyword 文章发布）和广告支柱（$199 起给，$199/$499 差异在归因/数据分析/监控深度，可能都不代客户投放，真正代投放留到定制档——待确认）有雏形，其余支柱还没过一遍
4. **定制档要不要重新设计**，还是直接沿用已有的 Enterprise FDE playbook（[`docs/registry/pricing-playbook-enterprise-fde.md`](../registry/pricing-playbook-enterprise-fde.md)：一次性 Setup $3,000 + Base 月费 $2,500 起 + 广告管理费边际阶梯，人力代做）——目前对话里没有专门重议这一档
5. 产品负责人提到一句"之前有 issue 总结的挺好：199 是被看到，499 是花钱被看到"——**已搜遍仓库 issue/PR/commit，没找到原文**，需要产品负责人口述复原这句话的具体意思
