# Magic Lab Class · 边走边拍 Walk & Talk #01 逐字稿（GA4 增强型衡量 / 真假 Leads）
# 大瑞 IP 口播稿。样片字幕来源；每非空行=一条字幕，# 开头行被忽略。**双星号**内=高亮词（黄色）。人设期无「报名/立即购买」CTA。
我今天要说的这件事，比「没装追踪」**严重得多**。
没数据**不可怕**。
**可怕**的是——
你有数据，但那个数据**可能是错的**。
很多公司装了 **GA4** 以后，会打开一个叫「**增强型衡量**」的功能。
这个功能很**方便**。
比如有人在你网站上填表，它可以**自动帮你记录**。
所以很多人一看：
今天 **10 个**表单提交。
OK，**10 个客户**。
但**问题**就在这里。
**GA4** 看到的「有人提交了表单」，**不一定等于**——
你真的拿到了一个**客户**。
举个最简单的例子。
一个客人在你网站上填完资料，点了 **Submit**。
**GA4** 可能看到：
好，**提交一次**。
但是后面到底**有没有成功**？
资料有没有真的**送出去**？
你的 **CRM** 有没有收到？
这个人最后有没有变成一个**真正的 Lead**？
这是**另外一回事**。
**反过来**也一样。
现在很多网站的表单越来越**复杂**。
多步骤的、弹窗的、第三方嵌进去的……
客人明明已经**提交成功**了，
**GA4** 也**不一定抓得到**。
所以最**麻烦**的事情出现了：
该算的，它**可能没算**。
不该算的，它又**可能算进去**了。
最后你看到 **GA4** 上写着：
「这个月 **37 个 Leads**。」
但这 **37 个**到底**是不是真的**？
**你不知道**。
然后你拿着这个**数字**去**决定**：
明天广告**加不加钱**？
哪个广告**应该停**？
**Meta** 和 **Google** 接下来应该去找什么样的人？
这才是真正**危险**的地方。
因为现在广告平台越来越依赖 **AI 自动优化**。
你喂给它**错误的数据**，它就会非常认真地帮你做**错误的优化**。
那我们**怎么做**？
其实没有那么**复杂**。
**第一**，别再直接把「有人点了提交」当成一个 **Lead**。
我们**真正要追踪**的是：
这个表单到底**有没有成功**。
**第二**，我们让 **Tag Manager** 去盯网站上那个：
「**提交成功**」
的提示。
只有这几个字真的**出现了**，
我们才告诉 **GA4**：
好，这次算一个**真正的 Lead**。
**第三**，再回到 **GA4**，把这个事件设成「**关键事件**」。
这样以后你看广告，就不是在看：
有多少人按过 **Submit**。
而是在看：
我到底拿到了多少个**真正的 Leads**。
还有一个很容易**忽略的坑**。
你今天才开始**正确记录**，
过去几个月的数据**不会自动变正确**。
所以这个东西越晚检查，你积累的**错误数据就越多**。
以前这种事情，你可能要**找人做**，要花**几百块**，自己研究也要折腾半天。
但现在我们已经开始让 **Claude 直接控制浏览器**做这些事情。
它**自己**打开网站，
自己找到「**提交成功**」出现在哪里，
再去 **Tag Manager** 把追踪**建起来**。
所以我越来越觉得：
**AI** 真正有价值的地方，不只是帮你写文案、做图片。
而是以前那些你**不会做**、**嫌麻烦**、**要花钱**找人做的事情，
现在 **AI** 可以开始**替你做**了。
最后你可以花 **30 秒**检查一件事：
打开 **GA4**，
看看你的表单到底有没有被正确记录成「**关键事件**」。
如果没有，
先别急着相信你后台那个**转化数字**。
先**搞清楚**一件事：
你看到的那些 Leads，到底是**真的客户**，还是 **GA4 以为的客户**。
